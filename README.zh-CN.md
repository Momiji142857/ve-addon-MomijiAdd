# VE Addon: MomijiAdd
[Mindustry](https://github.com/Anuken/Mindustry) 模组: 一个为 [Vanilla Expansion](https://github.com/Martian238/Vanilla-Expansion-Mod) (VE) 制作的内容扩展附属

[English](README.md) | **中文**

## 概述
本模组在 Vanilla Expansion 模组的基础上添加了一些额外内容, 基于个人偏好, 没有固定的修改方向. 可能会降低游戏难度或影响平衡性.
**请在使用前先启用 Vanilla Expansion 模组.**
