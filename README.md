# VE Addon: MomijiAdd
[Mindustry](https://github.com/Anuken/Mindustry) mod: a personal content add‑on for the [Vanilla Expansion](https://github.com/Martian238/Vanilla-Expansion-Mod) (VE)

**English** | [中文](README.zh-CN.md)

## Overview
This mod adds some extra content on top of the Vanilla Expansion mod, based on personal preference with no fixed direction. It may lower difficulty or affect game balance.  
**Enable the Vanilla Expansion mod before using this addon.**
